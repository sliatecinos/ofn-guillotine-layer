ofn-guillotine-layer (GIMP 3.x)

This plug-in implements something similar to Image>Guillotine at the layer level: the active layer(s) are sliced into new layers using the guides as division lines. The original layer is kept but made invisible.

The script is started from Layer>Guillotine. There are no parameters.

Installation (GIMP 3.x / 3.2)

Copy the ofn-guillotine-layer folder containing ofn-guillotine-layer.py into your GIMP user plug-ins directory. On Linux and macOS, ensure ofn-guillotine-layer.py is executable (chmod +x ofn-guillotine-layer.py).
